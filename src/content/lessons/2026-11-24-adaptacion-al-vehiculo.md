### Revisión preoperacional

<div class="def">

**Revisión preoperacional (taller preoperacional) (?):** lo que el conductor revisa **antes de salir**, en este orden: documentos, fluidos, llantas, luces, kit de carretera y testigos del tablero.

</div>

### 1. Documentos

| Documento | Qué revisar |
| --- | --- |
| SOAT | Vigencia. |
| RTM (revisión técnico-mecánica) | Vigencia. |
| Licencia de tránsito | Que coincidan la **placa** y el **color** del vehículo. |

### 2. Fluidos (líquidos)

**Aceite del motor:** se revisa con la **bayoneta** (varilla medidora).

| Qué mirar | Cómo debe estar |
| --- | --- |
| Color | Que no esté quemado ni negro. |
| Textura | Viscosa. |
| Topes | Entre el mínimo y el máximo de la bayoneta. |

Se cambia **por kilometraje o por tiempo**, lo que llegue primero:

| Vehículo | Cambio de aceite |
| --- | --- |
| Moto | Cada **2.500 a 3.000 km**, o cada **2 meses**. |
| Carro | Cada **5.000, 7.000 o 10.000 km**, según el aceite (?). |

**Otros fluidos:**

| Fluido | Qué revisar |
| --- | --- |
| Refrigerante | Nivel del depósito. Viene en **7 colores** (ver abajo). |
| Líquido de frenos | Entre el **tope máximo y el mínimo**; el depósito lleva un **pictograma**. Carro: cambio a los **10.000 km** (?). |
| Limpiaparabrisas | Agua. |
| Hidráulico (dirección) (?) | Se cambia según el **tiempo y el uso**. |

**Colores del refrigerante (7):** púrpura, verde, rojo, naranja, amarillo, azul y un séptimo que no se alcanza a leer en las notas (?).

> ¿Cuántos colores de refrigerante hay? R: **7**: púrpura, verde, rojo, naranja, amarillo, azul y uno más (?). (Mecánica: no es un artículo del CNT)

### 3. Llantas

| Qué revisar | Cómo |
| --- | --- |
| Desgaste | Con las **guías (testigos) de desgaste** del labrado o con un **profundímetro**. |
| Presión de aire (PSI) | La indicada en el **manual de instrucciones**, en el **lateral de la llanta** o, en la moto, en la **tijera**. |

### 4. Luces

El carro tiene **10 luces adelante** y **10 atrás**:

| Adelante (10) | Cant. | Atrás (10) | Cant. |
| --- | --- | --- | --- |
| Farola principal: altas | 2 | Luz de placa | 1 |
| Farola principal: bajas | 2 | Stop | 2 |
| Direccionales | 2 | Reversa | 2 |
| Parqueo | 2 | Direccionales | 2 |
| Tablero de instrumentos | 1 | Parqueo | 2 |
| Luz interior (techo) | 1 | Tercer stop | 1 |

### 5. Kit de prevención y seguridad vial

Es el equipo de carretera del **art. 30** (ver clase de infracciones; no llevarlo es infracción C11).

### 6. Testigos del tablero

El color del testigo dice qué tan grave es:

| Color | Significado |
| --- | --- |
| Verde | Aviso: un sistema está funcionando. |
| Rojo | Advertencia / alarma. |
| Amarillo | Señales / información. |

| Testigo | Qué indica |
| --- | --- |
| Sobrecalentamiento | El motor está muy caliente. |
| Combustible | Nivel bajo de combustible. |
| Puertas abiertas | Alguna puerta quedó abierta. |
| Cinturón de seguridad | Algún ocupante no tiene el cinturón puesto. |
| Falla de frenos | Advertencia en el sistema de frenos. |
| Check engine | Falla del motor. |
| Luces altas | Están encendidas las altas. |
| Luces bajas | Están encendidas las bajas. |
| Antiniebla | Están encendidas las antiniebla. |
| Estacionarias | Están encendidas las luces de parqueo. |

### Adaptación al vehículo (antes de arrancar)

Antes de arrancar, el conductor acomoda el puesto de conducción, en este orden:

| Paso | Ajuste |
| --- | --- |
| 1 | **Asiento del conductor:** espaldar (respaldo), distancia a los pedales y reposacabezas. |
| 2 | **Espejos laterales.** |
| 3 | **Espejo retrovisor** (el de adentro, para ver atrás). |
| 4 | **Ponerse el cinturón.** |
